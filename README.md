# SistemaRural PE

Diagrama de clases UML generado con [Graphviz](https://graphviz.org).

## Archivos

- `diagrama_clases.dot` — fuente del diagrama (DOT)
- `diagrama_clases.png` — diagrama renderizado
- `diagrama_clases.svg` — diagrama en formato vectorial

## Regenerar el diagrama

```bash
dot -Tpng diagrama_clases.dot -o diagrama_clases.png
dot -Tsvg diagrama_clases.dot -o diagrama_clases.svg
```
